# 表面素材

すべて[CC0 1.0](https://docs.ambientcg.com/license/)で、商用利用・改変・再配布が可能です。

| ディレクトリ | 配布元 | 使用画像 |
|---|---|---|
| `Metal061B` | [Metal 061 B](https://ambientcg.com/view?id=Metal061B) | Color・NormalGL・Roughness・Metalness |
| `Fabric062` | [Fabric 062](https://ambientcg.com/view?id=Fabric062) | Color・NormalGL・Roughness・AmbientOcclusion |
| `Plaster002` | [Plaster 002](https://ambientcg.com/view?id=Plaster002) | Color・NormalGL・Roughness |

配布ZIPは`https://ambientcg.com/get?file=<素材ID>_1K-JPG.zip`。
DisplacementとNormalDXは使用しません。素材画像による凹凸は法線に反映し、凹み本体の形状は変更しません。

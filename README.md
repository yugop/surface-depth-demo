# Surface Depth Demo

面の重なり・奥行き・光を試すWebデモ。白いMainLayerの背後に、側壁と底面が滑らかにつながるAILayerを描きます。Three.jsで3Dメッシュを生成し、専用シェーダーで光・影・反射を描画します。

開口の正面に固定した透視投影・平行投影を選べます。透視投影では奥の底面が小さく見え、側壁に奥行きが出ます。端末を傾けてもカメラと空間の位置関係は変わらず、光の方向・陰影・反射が変化します。

**[デモを開く](https://yugop.github.io/surface-depth-demo/)**

## 操作

- 「調整」でパネルを開き、外側をタップするか「×」で閉じます。「形状」「光と影」「素材」「グラデーション」「操作」の5カテゴリに分かれ、一度に1つだけ開きます。
- MainLayerの開き量は0〜100%。0%で白い全面、50%で下半分にAILayer、100%でAILayerの全面表示になります。初期表示はUnityのThinking2相当（36.4%）で、「Thinking2の配置に戻す」で開き量だけを復元できます。
- メインレイヤーに記事、AIレイヤーに予約準備の見出し・3項目・Ask Celia入力欄を表示します。Unityの400×880基準の配置を画面に合わせ、記事は画面に固定して白い面の輪郭で切り抜きます。Thinking2の一覧表示を固定したデモで、項目の進行・予約・入力処理は接続していません。Mark Proが端末にあれば使用し、なければArial／sans-serifで表示します。フォントファイルは配布しません。
- 「形状」の「凹みの形」で「皿」「お椀」を切り替えます。皿は平らな底へ曲がり具合も滑らかにつなぎ、お椀は開口から中央まで曲面が続きます。初期値はお椀で、選択も自動保存します。開口は両方とも同じ角丸長方形です。
- MainLayerの影と筐体の影は独立して切り替えられます。光源が大きいほど影が柔らかくなります。
- AILayerの深さ・皿の丸み（R）・ベース色と、光源の方向・大きさを調整できます。Rは皿の丸みの範囲で、厳密な円弧の半径ではありません。お椀ではRを使用しません。深さ・R・光源サイズは画面短辺、開き量は画面高さに対する割合です。
- 「皿のカーブ・水平倍率」は1倍が従来の形です。縦方向の丸みと深さを保ち、横方向だけを広げてなだらかにします。設定範囲は0.25〜5倍で、Rに応じて開口内に収まる上限まで使えます。R20%なら上限1.25倍、R5%なら5倍まで使えます。お椀・R0では使用しません。倍率も自動保存します。
- 「形状」の「カメラの画角（縦）」は20〜120°。画角に合わせてカメラ距離を調整し、開口面を画面にフィットさせます。大きいほど遠近感が強まり、底面が小さく見えます。画角も自動保存します。
- 「カメラの投影」で透視投影・平行投影を切り替えます。どちらも開口面を画面に合わせます。平行投影中は画角を使わず、透視投影へ戻すと設定した画角を復元します。投影方式も自動保存します。
- 傾き連動は起動時から常にONです。タップ時・ドラッグ終了時の姿勢を新しい基準にし、その後も連動を続けます。アクセス直後からセンサーを受信し、最初の姿勢を基準にします。起動時に利用許可を確認し、Safariが画面操作を要求した場合だけ最初のタップで許可確認を続けます。「操作」でも基準を更新できます。
- ドラッグは基準姿勢の更新に使います。光源の左右・高さは設定で調整できます。
- 「光と影」で直接光の明るさと補助光を調整できます。「素材」では「光源の反射」と「環境の映り込み」を個別に調整します。「表面の粗さ」は両方に作用し、小さいほどくっきり、大きいほどぼやけます。MainLayerは白を保ちます。
- 「素材」の「表面の素材」で単色・金属（Metal061B）・布（Fabric062）・プラスター（Plaster002）を選べます。画像素材は元の色と凹凸・粗さを使用し、金属は金属度、布は細部の陰影も反映します。「模様の繰り返し」で細かさを調整でき、粗さ65%が素材画像の基準です。単色ではベース色を使います。選択と繰り返しも保存します。[素材の配布元・ライセンス](public/materials/README.md)
- 「グラデーション」は表面の質感を保ちながら、紫・青・水色・淡い黄色のトーンをゆっくり変形させます。4色、色の強さ、大きさ、速度を調整でき、すべて保存します。初期値は強さ75%・大きさ100%・速度30%。強さ0%で元の素材色、速度0%でその時点の分布に静止します。大きさは画面短辺基準で、素材の模様とは独立します。金属では反射の色にも作用します。
- 「素材」の「環境」でLebombo（室内）、River Alcove、J&E Gray 02、Autumn Hill View、フロントカメラを選べます。「環境の基準角（Y）」は−180〜180°で、選択・角度も自動保存します。環境の強さは0〜300%。粗さを10〜20%に下げると像を確認しやすくなります。
- フロントカメラは「カメラを開始」で利用を許可し、「カメラを停止」で終了します。HDRへの切り替えやページを隠したときも停止します。再読み込み後は自動で起動しません。映像は端末内だけで処理し、録画・送信・音声取得はしません。
- どの設定を変更しても傾き連動を保ちます。
- 「初期値に戻す」で形状はお椀、開き量36.4%、MainLayerの影ON、筐体の影OFF、深さ20%、皿のR20%・水平倍率1倍、透視投影・縦画角82°、素材は単色・繰り返し1倍・色`#5C5C5C`、光源の左右0°・高さ60°・サイズ18%、明るさ88%、補助光11%、光源の反射20%、環境はLebombo・強さ100%・Y角0°、粗さ65%、傾きONに戻ります。

グラデーションも「初期値に戻す」で配色・強さ・大きさ・速度を戻し、色の動きを最初から再生します。

## 設定の保存

調整値は変更するたびに同じ端末・同じブラウザのlocalStorageへ自動保存し、閉じて開き直したときやアプリ更新後に復元します。新しい項目だけ初期値を使い、範囲が変わった項目は現在の範囲へ補正します。「初期値に戻す」は保存値も初期値に更新します。傾きの基準姿勢・センサー許可は保存対象に含めず、起動ごとに確認します。

別端末・別ブラウザへの同期機能はありません。ブラウザのサイトデータ削除やプライベートブラウズ終了などで保存値が失われる場合があります。Safariとホーム画面アプリ間の共有は保証しません。

## iPhoneで確認

Safariでデモを開き、共有からホーム画面に追加して、そのアイコンから起動してください。傾きセンサーには端末側の許可が必要です。

iPhone Airの縦画面を基準とし、標準表示では420×912 CSS px／描画1260×2736 pxを想定します。開口輪郭は[Apple公式寸法図](https://developer.apple.com/download/files/accessories/dimensional-drawings/iphone-air.pdf)の表示領域に基づきます。PCでは同じ縦横比のプレビューを表示します。他機種・表示倍率・Safariの操作バーによって全画面との一致は変わります。ステータスバーとホームインジケータはOS側の表示です。

## ローカル開発

Node.js 22.12以降の22系を使用します。

```sh
npm ci
npm run dev
```

PCで http://127.0.0.1:5173/ を開きます。

```sh
npm run build
npm run preview
```

`dist/` が静的配信ファイルです。相対URLなのでサブディレクトリにも配置できます。GitHub Pagesはmainへのpush時にGitHub Actionsでビルド・配信します。

## 制約

影と反射は観察用の近似です。MainLayerの角の半影は輪郭の局所近似、筐体の影は64点サンプリングを使います。環境は遠景の近似で、凹み・MainLayer同士の鏡像や環境反射の遮蔽は扱いません。実環境の光推定・ガラス・文字・表面テクスチャは扱いません。オフライン起動は保証しません。

カメラは前方の映像を反射方向に投影する近似で、360°画像ではありません。撮影範囲外は映像の平均色へなじませます。

同梱HDRはPoly HavenのCC0素材（1K）です。[素材の出典](public/environment/README.md)を参照してください。追加時は`public/environment/`へ画像を置き、`src/environments.js`の`ENVIRONMENTS`へID・表示名・URL・基準Y角を追加します。

計算方式と入力の責務は[Design.md](Design.md)を参照してください。

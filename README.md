# Surface Depth Demo

面の重なり・奥行き・光を試すWebデモ。白いMainLayerの背後に、側壁と底面が滑らかにつながるAILayerを描きます。Three.jsと専用シェーダーを使用します。

**[デモを開く](https://yugop.github.io/surface-depth-demo/)**

## 操作

- 「調整」でパネルを開閉します。「形状」「光と影」「素材」「操作」の4カテゴリに分かれ、一度に1つだけ開きます。
- MainLayerの開き量は0〜100%。0%で白い全面、50%で下半分にAILayer、100%でAILayerの全面表示になります。
- MainLayerの影と筐体の影は独立して切り替えられます。光源が大きいほど影が柔らかくなります。
- AILayerの深さ・底の角R・ベース色と、光源の方向・大きさを調整できます。深さ・R・光源サイズは画面短辺、開き量は画面高さに対する割合です。
- 傾き連動は初期状態でONです。画面タップ時の姿勢を基準にします。iPhoneの初回タップではセンサーの許可を要求し、許可後の最初の姿勢を基準にします。その後はタップするたびに基準を更新します。「操作」でもON/OFFと基準更新ができます。
- 描画面をドラッグすると光源方向が変わり、傾き連動を停止します。小さな指の揺れはタップとして扱います。
- 「光と影」で直接光の明るさと補助光を調整できます。「素材」ではAILayerの反射の強さ・粗さを調整します。粗さが小さいほど鋭い反射、大きいほど広い反射になり、反射0%でマットな表示に戻ります。MainLayerは白を保ちます。
- 光源方向の手動変更は傾き連動を停止します。開き量・深さ・R・色・影の変更は連動を保ちます。
- 「初期値に戻す」で開き量50%、MainLayerの影ON、筐体の影OFF、深さ20%、R20%、色`#5C5C5C`、光源の左右0°・高さ60°・サイズ18%、明るさ88%、補助光11%、反射20%、粗さ65%、傾きONに戻ります。

## iPhoneで確認

Safariでデモを開き、共有からホーム画面に追加して、そのアイコンから起動してください。傾きセンサーには端末側の許可が必要です。

iPhone Airの縦画面を基準とし、標準表示では420×912 CSS px／描画1260×2736 pxを想定します。開口輪郭は[Apple公式寸法図](https://developer.apple.com/download/files/accessories/dimensional-drawings/iphone-air.pdf)の表示領域に基づきます。PCでは同じ縦横比のプレビューを表示します。他機種・表示倍率・Safariの操作バーによって全画面との一致は変わります。ステータスバーとホームインジケータはOS側の表示です。

## ローカル開発

Node.js 22.12以降の22系を使用します。

```sh
npm ci
npm run dev
```

PCで http://127.0.0.1:5173/ を開きます。

```sh
npm run build
npm run preview
```

`dist/` が静的配信ファイルです。相対URLなのでサブディレクトリにも配置できます。GitHub Pagesはmainへのpush時にGitHub Actionsでビルド・配信します。

## 制約

影は観察用の近似です。MainLayerの角の半影は輪郭の局所近似、筐体の影は64点サンプリングを使います。間接反射・実環境の光推定・ガラス・文字・テクスチャは扱いません。オフライン起動は保証しません。

計算方式と入力の責務は[Design.md](Design.md)を参照してください。
